# Local Organic Food Marketplace

A full‑stack web application built with React (frontend) and Django REST Framework (backend) to connect local producers in Kosovo with consumers who want fresh, trustworthy food.  

Features include user accounts with buyer/seller roles, seller profiles, product management, browsing and search, orders with cart and checkout, ratings and reviews, and favorites.  

Tech stack: React, CSS, Django REST Framework, Python, SQLite.  

Project structure:
- frontend → React app
- backend → Django app  

How to run:
- Frontend: `cd frontend && npm install && npm run dev`
- Backend: `cd backend && pip install -r requirements.txt && python manage.py runserver`
